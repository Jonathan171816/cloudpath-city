# CloudPath City

Aprende Azure construyendo una ciudad de píxeles. Cada **casa** es un módulo de Microsoft Learn y cada **piso**, un submódulo: estudias con tarjetas, superas un reto y, en varios pisos, haces un **laboratorio simulado** que va armando tu **tenant** (grupos de administración, suscripciones, grupos de recursos y recursos). Cada laboratorio muestra el comando real de Azure CLI. Después ataca el **Equipo Brecha** y defiendes lo que construiste.

Ruta: **AZ-900** → **AZ-104** → **AZ-305** → Cima. Cada puerta se abre al subir tu certificado (o con una vista previa).

- Sin cuenta de Azure: los laboratorios son simulaciones.
- Preguntas originales, basadas en las guías de estudio oficiales de Microsoft. No se usó ni se reformuló ningún banco de preguntas de examen.
- El progreso se guarda en tu navegador (localStorage). El ranking es de ejemplo.
- Un solo archivo estático: `index.html`. Se reconstruye con `python3 build.py` (fuentes en `src/`).

Proyecto educativo independiente, no afiliado a Microsoft.
